파이프라인 아키텍처 분석

유도식 1~10 통합 파이프라인의 전체 흐름, 단계별 알고리즘, 그리고 실제 데이터 의존성을 정리한 문서.

10전체 단계
3기호+수치 혼합 단계
3실제 데이터 연결
4독립 계산 단계
01

전체 아키텍처 흐름

run_pipeline()이 빈 state 딕셔너리를 만든 뒤, step1부터 step10까지 순서대로 함수에 넘기고 각 함수가 갱신된 state를 반환하는 단일 선형 흐름. 보라색은 sympy 기반 기호 연산만 쓰는 단계, 청록색은 numpy 수치 계산이 포함된 단계.

  1. 1

    EM 라그랑지안

    L_EM = -(1/4)·F_μν·F^μν 를 기호로 정의.

    기호 연산
  2. 2

    아인슈타인 라그랑지안

    L_Einstein = R / (16πG) 를 기호로 정의.

    기호 연산
  3. 3

    Trig-Cantor 항

    κ·sin(Ax)cos(Bx)·R_Cantor 항을 합차공식으로 전개·검증하고, θ→π/2에서 발산하는 tan(k_total·x) 항(grad_trig)을 생성.

    기호 연산
  4. 4

    MHD 운동량 방정식

    3단계의 grad_trig를 source term으로 그대로 연결한 3D MHD 운동량 방정식을 세우고, 토이 u=sin(kx)e^(-νk²t)로 에너지 적분을 수치 검증.

    기호 + 수치
  5. 5

    버거스 방정식

    콜-호프 치환 u = -2ν(∂φ/∂ξ)/φ 을 버거스 방정식에 대입해 선형 열방정식으로 환원되는지 기호로 정리.

    기호 연산
  6. 6

    콜-호프 해 검증

    φ(ξ,t) = C_EL/√(4πνt)·exp(-ξ²/4νt) + C_EL 이 열방정식을 만족하는지 유한차분으로 수치 검증하고, 같은 점에서 u(ξ,t) 값을 추출.

    수치 연산
  7. 7

    쌍곡 메트릭

    메트릭 g = diag(-1,1)/ξ² 으로부터 크리스토펠 기호를 거쳐 리치 스칼라 곡률 R을 기호로 직접 계산.

    기호 연산
  8. 8

    곡률 가속도 벡터

    7단계의 ξ_sym을 그대로 재사용해 H_μ = -(1/ξ²)·∇_μξ 를 계산하고 ξ=1,2,5에서의 값을 평가.

    기호 연산
  9. 9

    ODE 기울기

    du/dξ = C_EL·K_dim/cosθ 의 θ→0 극한을 구한 뒤, 6단계에서 나온 C_EL_val 수치를 대입해 실제 값까지 계산.

    기호 + 수치 대입
  10. 10

    슈뢰딩거 기댓값

    예시 파동함수 ψ=√2·sin(kπx)에 대해 Γ(ξ)=⟨ψ|H|ψ⟩ 를 기호 적분으로 계산. 이전 단계와 무관한 독립 계산.

    기호 연산
02

단계별 알고리즘 상세

각 단계가 다루는 수식, 계산 방식, 그리고 state 딕셔너리에서 실제로 읽어들이는 입력과 새로 만들어내는 출력 키.

단계수식방식입력(이어받음)출력(생성)

→ tan(k_total·x) 발산항		 기호 없음 (신규 기호 도입) grad_trig, L_trig, identity_check
4. MHD 운동량 방정식 ρ(∂u/∂t + u·∂u/∂x) =
-∂p/∂x + (curl B×B) + source		 기호+수치 grad_trig, x (3단계) momentum_eq, energy_integral

θ→0 극한		 기호+수치 대입 C_EL_val (6단계) du_dxi_numeric

03

실제 데이터 의존성

각 단계의 docstring은 "이전 단계를 이어받는다"고 적혀 있지만, 실제 코드에서 직전 단계가 만든 값을 입력으로 사용하는 연결은 9번의 전환 중 3번뿐이다. 나머지는 같은 state 딕셔너리를 거쳐가는 순차 실행일 뿐, 실제 수학적 종속 관계는 없다.

실제 데이터 연결 (3건)

3→4grad_trig, x 전달
7→8xi_sym 전달
6→9C_EL_val 전달

순차 실행만 (실제 데이터 없음)

1···2···3사전 단계 결과 미사용
4···5···6사전 단계 결과 미사용
8···9···10사전 단계 결과 미사용

완전히 독립적인 계산 (입력도 출력도 다른 단계와 실제로 연결되지 않음)

1단계 2단계 5단계 10단계
04

종합 정리

1, 2, 5, 10단계는 사실상 독립적인 계산이고, 4·8·9단계만 직전 단계의 결과를 실제로 입력으로 사용한다(3→4, 7→8, 6→9). 즉 "단계가 이어받는다"는 주석 표현은 절반 정도는 흐름의 형식 — 같은 state 딕셔너리를 통과한다는 의미 — 일 뿐이고, 실제 수학적 종속 관계는 그보다 적다.
